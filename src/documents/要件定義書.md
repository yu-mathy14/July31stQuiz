# 1. 目的・背景
### このアプリで何を実現するか：
既習事項であるTypeScript,React等を用いてクイズを作成し、プレイ・結果確認までを1つのアプリで行えるクイズ出題アプリを作成する。

### 想定利用者：
JavaScript・TypeScript・Reactの学習者

---

# 2. 機能一覧
| ID | 機能名 | 概要 | 備考 |
|----|--------|------|------|
| F-1 | 作問フォーム | 問題文・選択肢・正解・解説・制限時間・カテゴリを入力し、バリデーションを満たした問題を登録する。登録後は一覧へ即時反映する。 | React Hook Form + Yup |
| F-2 | スタート画面 | 出題カテゴリ（すべて・JavaScript・TypeScript・React）と出題順（登録順・シャッフル）を選択し、クイズを開始する。 | フィルタ・シャッフル処理 |
| F-3 | 制限時間タイマー | 問題ごとに制限時間をカウントダウン表示する。0秒になると自動的に時間切れとして解説画面へ遷移する。 | useEffect・useRef |
| F-4 | 回答・判定 | 選択肢をクリックすると正誤判定を行い、解説を表示する。正解時はスコアを加算し、回答後はタイマーを停止する。 | 回答は1回のみ |
| F-5 | 次の問題へ | 「次へ」ボタンで次の問題へ進み、タイマーを初期値へリセットする。最後の問題終了後は結果画面へ遷移する。 | Reducerで状態管理 |
| F-6 | 結果・復習 | 正答数・正答率・所要時間を表示し、不正解だった問題のみを復習リストとして表示する。「もう一度」で最初からプレイできる。 | map・filterを使用 |
| F-7 | 状態管理 | クイズ進行をuseReducerで管理し、開始・回答・時間切れ・次の問題・終了などの状態遷移を一元管理する。 | 状態機械として実装 |

# 3. 挙動要件（非機能）
| ID | 挙動要件 | 期待する具体的な動き |
|----|----------|----------------------|
| T-1 | タイマーのリセット | 問題が切り替わるたびに制限時間を初期値へ戻し、新しいカウントダウンを開始する。 |
| T-2 | 回答後の停止 | 回答した時点、または時間切れになった時点でタイマーを停止し、0秒未満にはならない。 |
| T-3 | クリーンアップ | setIntervalはuseEffectのクリーンアップ関数で解除し、画面遷移やアンマウント後もタイマーが動作し続けない。 |
| T-4 | 二重回答防止 | 一度回答すると選択肢は無効化され、再度クリックしても判定やスコアは変更されない。 |

# 4. データ定義
```ts
export type Category =
  | "JavaScript"
  | "TypeScript"
  | "React";

export type Choice = {
  id: number;
  text: string;
};

export type Question = {
  id: string;
  question: string;
  choices: Choice[];
  answer: number;
  explanation: string;
  limit: number;
  category: Category;
};
```

### 型の補足

| プロパティ | 理由 |
|------------|------|
| id | 一覧表示時のkeyとして使用するため |
| limit | 問題ごとに制限時間を設定できるようにするため |
| category | カテゴリ検索・絞り込みを行うため |

# 5. バリデーション仕様
| フィールド | ルール | エラーメッセージ |
|------------|---------|----------------|
| 問題文 | 必須・5〜200文字・前後空白除去 | 問題文は5文字以上で入力してください。 |
| 選択肢1〜4 | 必須・60文字以内・重複不可 | 選択肢が重複しています。 |
| 正解 | 必須・1〜4のいずれか | 正解を選択してください。 |
| 解説 | 必須・10文字以上 | 解説は10文字以上で入力してください。 |
| 制限時間 | 必須・整数・5〜120秒 | 制限時間は5〜120秒で入力してください。 |
| カテゴリ | 必須・JavaScript、TypeScript、Reactのいずれか | カテゴリを正しく選択してください。 |

# 6. 判断ログ

| 論点 | 決めたこと | 理由 |
|------|------------|------|
| 時間切れ時の扱い | 不正解として解説画面へ進む | 設定時間内に回答することができないということは不正解として扱い、復習対象に含めたいため。 |
| 出題順 | 登録順とシャッフルを選択可能にする | 同じ問題でも繰り返し学習しやすくするため。 |
| 回答後の操作 | 選択肢を押せないようにする | 二重回答を防ぎ、正しい採点を行うため。 |
