# 1. 画面一覧・画面遷移

本アプリは「作問モード」と「プレイモード」の2つの画面で構成する。

```
作問モード ⇄ プレイモード

プレイモード
StartScreen
      ↓
QuestionScreen
      ↓
回答・時間切れ
      ↓
解説表示
      ↓
次の問題
      ↓
ResultScreen
      ↓
もう一度
      ↓
StartScreen
```

---

# 2. コンポーネント構成

```
App                       … 問題データを管理し、作問・プレイモードを切り替える
├── Panel                 … 見出しと枠線を表示する共通レイアウト
├── QuizAuthoring         … 作問画面全体を管理する
│    ├── QuestionForm     … 問題を入力・登録するフォーム
│    └── QuestionList     … 登録済み問題を一覧表示する
│         └── QuestionItem… 問題1件分を表示する
└── QuizRunner            … クイズ全体の進行を管理する
     ├── StartScreen      … 出題条件を選択して開始する
     ├── QuestionScreen   … 問題・選択肢・解説を表示する
     │    └── Timer       … 制限時間をカウントダウンする
     └── ResultScreen     … 結果と復習問題を表示する
```

# 3. 状態機械の設計（useReducer）

## 3-1. 状態遷移図

```
idle
  │
  ▼
playing
  │
  ├──回答
  ▼
answered
  │
  ├──次へ
  ▼
playing
  │
  └──最後の問題
  ▼
finished
  │
  └──もう一度
  ▼
idle
```

---

## 3-2. State の形

```ts
type QuizState = {
  status: "idle" | "playing" | "answered" | "finished";
  order: Question[];
  currentIndex: number;
  score: number;
  answers: {
    questionId: string;
    choiceId?: string;
    isCorrect: boolean;
    elapsedTime: number;
  }[];
};
```

---

## 3-3. Action一覧

| Action  | payload    | 状態の変化          |
| ------- | ---------- | -------------- |
| START   | 出題カテゴリ・出題順 | 問題を抽出してクイズ開始   |
| SELECT  | choiceId   | 回答を保存し正誤判定する   |
| TIMEOUT | なし         | 不正解として解説表示へ移る  |
| NEXT    | なし         | 次の問題へ進む        |
| RESTART | なし         | スコア・回答履歴を初期化する |

---

## 3-4. なぜ useState ではなく useReducer か

クイズでは「現在の問題番号」「スコア」「回答履歴」「画面状態」など複数の状態が同時に変化する。そのため、それぞれを useState で管理すると更新処理が複雑になる。

useReducer を利用することで、状態遷移を reducer にまとめることができ、状態の変更ルールを1か所で管理できるため、保守性が高く分かりやすい実装になる。

# 4. フックの採用理由

| フック            | 使用箇所       | 目的・理由                                 |
| -------------- | ---------- | ------------------------------------- |
| useReducer     | QuizRunner | クイズ全体の状態遷移を管理するため                     |
| useEffect      | Timer      | カウントダウンを行い、終了時にタイマーを解除するため            |
| useRef         | Timer      | interval ID を保持し、clearIntervalで停止するため |
| useState       | App        | 問題一覧を管理するため                           |
| useContext（任意） | 使用しない      | 今回はPropsで十分受け渡しできるため                  |

---

## 4-1. Timer のクリーンアップ設計

Timer コンポーネントでは useEffect の中で setInterval を開始する。

依存配列には制限時間や回答状態を指定し、問題が切り替わるたびに新しいタイマーを開始する。

useEffect の戻り値（クリーンアップ関数）で clearInterval を実行し、画面遷移・回答完了・アンマウント時にタイマーが残らないようにする。
